פותח ע"י נוי נוביק

כתוב שם של חומר באנגלית (או נוסחה, כמו NaCl), והאתר ימשוך מהמאגר של PubChem את הנוסחה, המסה המולרית, המבנה, תכונות פיזיקליות וסימוני הבטיחות. בתחתית הכרטיס יש מחשבון מולים שמשתמש במסה המולרית שהתקבלה.

הנתונים נמשכים בזמן אמת מ-PubChem (המכון הלאומי לבריאות, ארה"ב) דרך ה-API הציבורי PUG REST ו-PUG View, ללא מפתח. ערכים ניסיוניים מגיעים ממקורות שונים ועשויים להיות שונים מספרי הלימוד. מסה מולרית מחושבת לפי מסות אטומיות עדכניות, ולכן ייתכן הבדל קטן מהנוסחאון של הבגרות (למשל 58.44 לעומת 58.5 ל-NaCl).
